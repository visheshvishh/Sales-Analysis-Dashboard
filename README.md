## Project Overview
This project focuses on analyzing sales transaction data using Power BI and MySQL. It uses structured sales data, customer information, product categories, market locations, and date dimensions to support business analysis.

## Technologies Used
- **Power BI:** Business intelligence and data visualization
- **MySQL:** Database storage and SQL data management
- **SQL:** Data querying and relational data analysis

## Dataset Structure
The database includes the following tables:

- `transactions` — Product, customer, market, order date, sales quantity, sales amount, and currency.
- `customers` — Customer names and customer types.
- `products` — Product codes and product types.
- `markets` — Market names, codes, and zones.
- `date` — Calendar dates, years, and month information.

## Project Objectives
- Analyze sales transactions across markets and customers.
- Explore sales quantities and sales amounts over time.
- Examine customer types and product categories.
- Organize sales data for business intelligence reporting.
- Present sales information through Power BI visualizations.

## Files Included
- `Sales Analysis.pbix` — Power BI report file.
- `db_dump.sql` — MySQL database export.

## How to Use
1. Import `db_dump.sql` into MySQL Server.
2. Open `Sales Analysis.pbix` in Power BI Desktop.
3. Configure the database connection if prompted.
4. Refresh the data and explore the report.

## Skills Demonstrated
Power BI, MySQL, SQL, data analysis, relational databases, and business intelligence.
